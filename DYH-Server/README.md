## 📂 Guía de Carpetas (Workflow)

Para mantener el orden y evitar conflictos de Git:

1.  **playground/**: Zona de caos.
    * Aquí vive TU carpeta personal (ej. `playground/Mario`).
    * Puedes subir archivos rotos, pruebas y experimentos.
    * **Nadie debe tocar la carpeta de otros sin avisar.**
2.  **src/**: Zona sagrada.
    * Aquí va solo el código que **funciona**.
    * Se utiliza a partir de la Semana 3 para la integración.

```text
DYH-Server/
├── 📂 playground/       <-- TRABAJO INDIVIDUAL (Semanas 1-2)
│   ├── 👤 Mario/
│   └── ...
├── 📂 src/              <-- CÓDIGO FINAL COMPARTIDO (Semana 3+)
│   └── (Componentes finales del Squad)
└── 📄 README.md
```
